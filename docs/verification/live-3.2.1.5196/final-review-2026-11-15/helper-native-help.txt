bandcamp-cookie-push --client-name <exact owner name> --fan-id <expected fan id> [--url <HTTPS Lidarr URL>] [--authelia]
Set LIDARR_API_KEY privately. --authelia requires LIDARR_AUTHELIA_ORIGIN (exact Lidarr HTTPS origin) and LIDARR_AUTHELIA_SESSION (only the session value); LIDARR_AUTHELIA_COOKIE_NAME defaults to authelia_session. Proxy sessions stay in memory and are never sent to Bandcamp. Redirect minimal identity on stdin for manual import; otherwise a visible isolated browser opens. Complete login/CAPTCHA/2FA yourself. Ctrl-C requests cancellation before the server commit boundary. Keep the operation ID for reconciliation. Use --session-status with --client-name to read the last observed session state without login or validation. Use --renewal-status <id> or --cancel-renewal <id> with --client-name and the same server.
