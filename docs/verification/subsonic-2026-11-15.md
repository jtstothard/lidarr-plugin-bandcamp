### Decision: NO-GO for preferred lossless collection provider on current evidence

The tested working Subsonic retrieval delivers MP3 even for raw/FLAC requests, while web offers lossless formats; the standard download route used by a supported client's source returns an error. Do not implement or enable Subsonic as a silent replacement for web archive downloads. Retain web as primary. A separately scoped streaming/explicit-lossy feature may be technically feasible but is not this spec's accepted preferred-provider outcome. This is a bounded decision for observed implementation/account/sample, not proof that no alternate or future lossless route exists.
